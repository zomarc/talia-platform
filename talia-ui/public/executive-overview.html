Executive summary

Talia is Celestyal's revenue and inventory intelligence platform. It connects the Azure Synapse data lake to an interactive analytics workspace where commercial, revenue, and operations teams explore sailing schedules, pricing, reservations, agencies, and competitor intelligence — through customizable dashboards with linked cross-filtering.

Data flows one way from Synapse into a local Supabase serving layer; the React UI queries a GraphQL API. The same Docker stack runs on a developer laptop, a LAN staging MiniPC, and an Azure MVP VM — deployed from the laptop via tarball scripts.

  • Source: Azure Synapse (dwh · stg · fou)
  • Serving: Supabase Postgres + GraphQL API
  • Presentation: React · Dockview · Tabulator · Chart.js
  • Environments: Local · Staging · MVP · taliahub.com
  • Status: Alpha — client demo ready on staging
  • Next horizon: talia-engine intelligence layer (planned)

What we have achieved

  • Monorepo platform — independent talia-ui and GraphQL server with unified versioning.
  • Supabase data platform — full Docker stack (Postgres, Kong, Auth, PostgREST, Realtime, Storage, Studio).
  • Azure Synapse integration — config-driven sync of dimensions and facts from the data lake.
  • Agency dimension — dwh.Dim_Agency (~40k agencies) with a filterable Agency Directory.
  • Analytics workspace — Master Sailing, Published Rates, Reservation state, Competitor Pricing.
  • Demand insight — heatmaps, booking profiles, KPI and revenue breakdowns.
  • Dockview workspace — customizable, event-linked layouts with persistence.
  • Library-first UI (0.2.1) — shared Tabulator config, global Fit Width/Data, grouped-row fix.
  • External feeds — Google Search/Trends, competitor pricing, and ship AIS integration paths.
  • Ops toolchain — scripts/validate, tarball deploy to staging and MVP, version cross-check.
  • Multi-environment delivery — local, MiniPC staging, Azure MVP, and external demo via taliahub.com.
  • Documentation stack — canonical index, archive policy, environment runbooks, executive overview.
