# Archive Documentation Policy

This directory contains historical and superseded documentation.

## Important

- Archive docs are reference material only.
- Do not treat archive docs as current implementation guidance.
- For active development, use canonical docs listed in:
  - `docs/DOCS-CANONICAL.md`
  - `docs/DIRECTIVE.md`

## Why this exists

The project has multiple legacy tracks (ngrok setup, staging notes, migration notes). The archive preserves history without changing active standards.
