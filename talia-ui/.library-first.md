# 🚀 Library-First Development

## Quick Reference Card

**RULE**: Always check the library documentation before writing custom code.

---

## Tabulator Checklist

Before writing any table code, check:

- [ ] Can I use `valuesLookup` instead of manual filter extraction?
- [ ] Can I use `initialSort` instead of pre-sorting data?
- [ ] Can I use `resizableColumns` instead of custom resize handlers?
- [ ] Can I use `movableColumns` instead of custom drag handlers?
- [ ] Can I use built-in formatters instead of custom renderers?
- [ ] Can I use built-in themes instead of custom CSS?

---

## Code Pattern: Good ✅ vs Bad ❌

### Filters
```javascript
// ✅ GOOD
headerFilterParams: { valuesLookup: true }

// ❌ BAD  
headerFilterParams: { values: manuallyExtracted() }
```

### Styling
```javascript
// ✅ GOOD
new Tabulator(element, {
  theme: 'default',
  layout: 'fitColumns'
});

// ❌ BAD
element.style.border = '1px solid';
element.style.padding = '10px';
// ... 50 lines of CSS
```

### State Management
```javascript
// ✅ GOOD
const { data, loading, error } = useSailingData();

// ❌ BAD
const [data, setData] = useState([]);
useEffect(() => {
  fetch('/api').then(r => r.json()).then(setData);
}, []);
```
