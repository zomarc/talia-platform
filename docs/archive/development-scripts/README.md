# Development Scripts Archive

This directory contains temporary development and testing scripts that were created during feature development. These scripts are kept for reference but are not part of the main codebase.

## Structure

- **ngrok/** - Scripts for managing ngrok tunnels and configuration
- **reservation/** - Scripts for testing and verifying reservation data fixes
- **inventory/** - Scripts for testing inventory status sync functionality

## Purpose

These scripts were used during development and testing phases. They may be useful for:
- Understanding how features were tested
- Debugging similar issues
- Reference for future development

## Note

These scripts are not actively maintained and may require updates to work with current codebase. For production scripts, see the main `scripts/` and `talia-server/scripts/` directories.
