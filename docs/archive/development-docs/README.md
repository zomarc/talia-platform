# Development Documentation Archive

This directory contains temporary development documentation files that were created during feature development and debugging sessions. These files are kept for reference but are not part of the main documentation.

## Structure

- **ngrok/** - Documentation related to ngrok setup and configuration
- **reservation/** - Documentation related to reservation data fixes and debugging
- **general/** - General development documentation, commit summaries, and implementation notes

## Purpose

These files were archived to keep the repository root clean while preserving development history and context. They may be useful for:
- Understanding the development process
- Debugging similar issues in the future
- Reference for implementation decisions

## Note

These files are not actively maintained and may contain outdated information. For current documentation, see the main `docs/` directory.
